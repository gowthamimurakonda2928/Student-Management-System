# Student Management System

A simple web-based Student Management System developed using Python and Flask.

## Features

- User Registration
- User Login
- Add Student Details
- Edit Student Details
- View Student Details
- Student Management Dashboard

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Project Structure

- app.py - Main Flask application
- templates/ - HTML pages
- css/ - CSS files
- js/ - JavaScript files
- database.db - SQLite database

## How to Run

1. Install Python.
2. Install Flask using: pip install flask
3. Run the application using: python app.py
4. Open the local URL shown in the terminal.

## Project Purpose

This project demonstrates the basic implementation of a web-based Student Management System using Python Flask, HTML, CSS, JavaScript, and SQLite.
